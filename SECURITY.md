# Security Policy

| Version | Supported          |

| `main`  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

Security is a top priority for the Apartment Management System. If you discover a vulnerability, please do **NOT** create a public issue on GitHub. Instead, follow this process to report it responsibly.

### How to Report

Please report security issues or vulnerabilities directly to the author:

> [LinkedIn](https://www.linkedin.com/in/dabanandamitra/) - [Facebook](https://www.facebook.com/dabanandamitra/) - [WhatsApp](https://wa.me/@dabananda) - [X](https://x.com/dabanandamitra) - [GitHub](https://github.com/dabananda) - [Email](mailto:dabananda.dev@gmail.com)

### What to Include in Your Report

To help us resolve the issue quickly, please provide the following details:
1. **Description**: A clear description of the vulnerability and its potential impact.
2. **Steps to Reproduce**: Detailed instructions on how to replicate the issue.
3. **Environment**: Any relevant details about your setup (e.g., specific browsers, operating systems, configuration settings).
4. **Suggested Fix (Optional)**: If you have an idea of how to resolve the vulnerability, we welcome your suggestions.

### Response Time

You can expect a prompt acknowledgment of your report. We aim to address all verified vulnerabilities as quickly as possible. Once the issue is resolved, we will publish a fix and, if appropriate, acknowledge your contribution.
